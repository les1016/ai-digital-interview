## 对抗性场景

- 未登录读取面试返回 401；另一普通用户读取该面试和录像返回 404。
- 数字人管理接口拒绝未登录和普通用户；会话控制校验所有者。HTTP/WebSocket 测试覆盖正常访问、越权、鉴权服务故障和票据过期/伪造/用途错误。
- 注册限流跨用户名聚合；退出通知凭证不能登录；数字人短期凭证不能访问普通应用 API。
- 删除带强退记录的面试时保留冷却计数，测试启用了真实外键约束。
- 同名预算锁及持有旧引用的操作锁维持互斥。
- ASR 模型异常返回可重试错误，不再伪装成空回答；重复失败后队列槽位仍可释放。

## 实测发现并修复的额外问题

1. WSL 选项被整体加引号，导致数字人进程无法启动；改为单独处理 WSL 选项和脚本路径，并加入带中文及空格路径的原生启动测试。
2. Shell 脚本的 CRLF 换行导致 bash 拒绝执行；通过 Git 属性固定 LF。
3. WSL 无法通过自己的 loopback 访问 Windows 后端，且跨系统读取活动 SQLite 有锁兼容问题；改为后端签发 120 秒的 avatar 专用票据，开发环境本地验签，生产环境仍通过内部鉴权端点验证。
4. 旧版 edge-tts 返回 HTTP 403；更新至上游 7.3.1，并记录补充依赖。
5. ASR 在已有缓存时仍走失效代理请求模型仓库；优先使用本地快照并关闭自动更新检查。
6. 播报没有真正开始时，页面可能静默继续；现在进入明确的浏览器语音回退流程。
7. 模型报告结构异常时的本地补全缺少明确来源标记；现在保存并显示降级状态，导出用免责声明也保留提示。
