## 想试用，选哪种方式？

| 目标 | 开始方式 | 需要什么 |
| --- | --- | --- |
| 先了解界面 | 阅读本页截图和首页功能说明 | 不安装、不填 Key；不是在线交互演示 |
| 研究业务页面与 API | 完成首页初始化和本机配置，再用“仅启动网页与后端.cmd” | Python、Node.js 等环境；实时文本面试仍可能产生 API 费用 |
| 固定剧本测试 | 在自己的部署中，以自己创建的管理员登录 | 问答不调用 DeepSeek；语音、数字人播放仍需对应服务和素材 |
| 完整数字人语音面试 | 按第三方说明部署 LiveTalking 等服务 | GPU / 模型运行环境、授权素材、语音服务及自己的模型 Key |

目前没有公开在线体验服务器。克隆本仓库不会自动获得作者的账号、API 额度、人物或模型权重。详见 [首次运行](../README.md#windows-本地首次运行) 与 [第三方组件说明](THIRD_PARTY.md)。

## 图片发布审核

公开图片仅包含一张经项目维护者选定的面试官形象展示图，以及三张虚构数据界面截图。发布工具仅为这四个确切路径和 SHA-256 放行，不允许任意 PNG，也不把图片通过校验等同于自动识别了全部隐私。更新图片需重新检查像素内容、文字、元数据和授权，再更新审核摘要。其他测试头像、建模参考图、操作截图不纳入发布。

数字人动作视频、模型权重和人物建模资源不纳入公开预览。这些图片不证明数字人、语音或文档转换的完整链路已在观看者的设备上通过测试。
