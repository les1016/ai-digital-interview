# 工具箱审查问题修复（2026-10-29）

对应本次审查确认的四项问题。本说明记录修复与本地验证结果；公开版本通过独立的脱敏发布流程同步，实际发布状态以仓库提交记录为准。修复没有变更真实账号、简历、面试录像或私人剧本原件。

## 修复内容

1. **私人管理员剧本**：移除前端 JSON 静态导入，改为管理员鉴权的 `GET /api/admin/demo-script`，响应 `Cache-Control: no-store`。保留本机文件原位置及内容。开发服务拒绝直接读取该文件，管理台具备加载、错误、重试、退出和取消状态。
2. **跨标签会话**：localStorage 为空时不再复用旧内存凭据；访问 storage 抛异常时仍支持内存登录。监听跨标签退出、切号与清空事件，先卸载旧用户界面再恢复新身份；取消旧请求，忽略迟到结果，阻止旧界面携新账号凭据提交数据。
3. **异常锁释放**：四个录像/文档入口共用 `operation_capacity`，并发槽获取失败或释放失败时仍确保操作锁清理；删除入口也保证多把锁的嵌套清理。
4. **录像配额**：完整上传与分片上传的最终配额检查、文件提交使用同名协调锁，删除、回滚和崩溃恢复遵守相同顺序。锁忙时立即返回可重试的 429，不阻塞异步事件循环。隔离区中尚未真正删除的录像继续计入配额。

跨进程协调依赖生产配置中的 Redis；本地开发由既有进程内锁协调。本次没有对真实 Redis 服务故障或网络分区做部署级验证。
